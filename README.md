# Algorand Certificate Verification

## Overview

This project is a blockchain-based certificate verification system
built using the Algorand blockchain.

The system aims to provide a secure and transparent way to verify
the authenticity of digital certificates.

## Objectives

- Store certificate verification information on Algorand
- Prevent unauthorized modification of certificate records
- Provide a simple verification mechanism
- Explore Algorand blockchain and smart contract concepts

## Technologies

- Algorand
- Python
- Algorand SDK
- PyTeal / Algorand Smart Contracts
- GitHub
